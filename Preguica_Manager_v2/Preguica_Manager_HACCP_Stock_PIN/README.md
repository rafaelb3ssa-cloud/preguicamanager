# Preguiça Manager — Fichas Técnicas integradas

Esta versão importa as 76 fichas do ficheiro `Preguica_Fichas_Tecnicas_Custos_Mercado.xlsx` para a secção **Fichas técnicas**.

## O que está incluído
- Pesquisa por produto/ingrediente e filtro por categoria.
- Preço de venda, custo estimado, margem bruta estimada e margem percentual.
- Edição e criação de fichas.
- Exportação CSV.
- Guarda local no navegador (localStorage).

## Importante
Esta continua a ser uma versão estática de demonstração. Os dados guardados no navegador não sincronizam entre dispositivos nem utilizadores e podem não estar disponíveis noutro navegador. Para utilização real em telemóvel e computador, é necessário ligar autenticação e base de dados (por exemplo, Supabase) e configurar as permissões de segurança.

Os custos são estimativas gerais de mercado grossista/retalho, não preços de artigos específicos confirmados em tempo real na Makro/Recheio. Validar receitas, gramagens, preços de compra, IVA e alergénios antes de usar operacionalmente.

## Publicação
Substituir o conteúdo do projeto atual por estes ficheiros no repositório ligado à Vercel, ou publicar este ZIP como projeto separado. A Vercel deverá fazer um novo deployment após o commit.
