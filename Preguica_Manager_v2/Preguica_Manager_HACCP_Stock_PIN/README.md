# Preguiça Manager — fichas técnicas integradas

Esta cópia mantém as 76 fichas de referência do ZIP, com pesquisa, filtro por categoria, edição e exportação CSV. Os custos são estimativas e precisam de validação com as faturas e receitas reais.

A página é ainda uma demonstração estática: as alterações às fichas ficam apenas neste navegador e não sincronizam com o Supabase. O login por PIN no navegador foi removido; esta versão não implementa autenticação. O manual HACCP aprovado do estabelecimento continua a ser a referência e esta página não define limites de temperatura.
